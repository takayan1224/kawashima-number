川島数を調べる

約数の和が、入力した数と等しくなる整数を探します。

約数の和

σ(n) = k

σ(n) は n の正の約数をすべて足した値。

数を入力

1 〜 1,000,000 の整数

入力例

計算結果

個あなたの川島数

約数の和がこの値になる整数はありません。

    計算のしくみ

    1. 候補は 1 から k まで。n 自身が約数なので、約数の和は n 以上です。
    2. 各整数 d を、その倍数すべての約数の和に加えます。
    3. 約数の和が k と一致した整数を集め、個数を表示します。
    サイトで動く計算コード JavaScript
    元のプログラム Python 
    import sympy
import numpy as np
k=1224
t= np.arange(1,k+1)
table= np.array([sum(sympy.divisors(i)) for i in t])
table= t[table==k]
print(f"あなたの川島数は{len(table)}でその数は{table}です")
