Σ カワシマ数 プログラム

カワシマ数を調べる

約数の和が、入力した数と等しくなる整数を探します。

数を入力

1 〜 1,000,000 の整数

計算結果

個あなたのカワシマ数

約数の和がこの値になる整数はありません。

    プログラム

    import sympy
import numpy as np
k=1224
t= np.arange(1,k+1)
table= np.array([sum(sympy.divisors(i)) for i in t])
table= t[table==k]
print(f"あなたの川島数は{len(table)}でその数は{table}です")

    このプログラムはO・S氏によって作られました。
