# カワシマ数を調べる

正の整数 `k` を入力すると、正の約数の和が `k` になる整数とその個数を表示します。初期値の `1224` では `606, 670, 1111, 1139, 1223` の5個です。結果の整数を選ぶと約数の内訳が表示されます。

## 手元で使う

`index.html` をブラウザーで開きます。計算はページ内の JavaScript で行います。対応する入力は 1 から 1,000,000 までの整数です。ページ下部の「プログラム」に元の Python コードを掲載しています。

## GitHub Pages で公開する

1. GitHub で公開リポジトリを作成し、`index.html` と `README.md` をリポジトリのルートに置きます。
2. リポジトリの **Settings → Pages** を開き、**Source** で **Deploy from a branch** を選びます。
3. ファイルを置いたブランチ（通常は `main`）と **/(root)** を選び、**Save** を押します。
4. デプロイ後、同じ **Pages** 画面の **Visit site** から開きます。

[GitHub Pages の公開元を設定する（GitHub Docs）](https://docs.github.com/ja/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
